Create the module:

```python
"""Single source of truth for the Tool Arena task taxonomy.

The wire format stays a string (the `task_type` JSON field) for back-compat.
This module owns the contract: which task types exist, what each demands of
the caller, and which mediator handles its output.

Adding a new task type = add one TaskKind entry. Dispatcher / mediator /
pill loader / frontend all read from here.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Literal

TaskKindId = Literal["summary", "qa"]


@dataclass(frozen=True)
class TaskKind:
    id: TaskKindId
    requires_document: bool
    mediator_id: str            # name of the TaskMediator adapter (plan 13-03)
    display_label_key: str      # i18n key — frontend resolves via Paraglide


SUMMARY = TaskKind(
    id="summary",
    requires_document=True,
    mediator_id="summary",
    display_label_key="toolArena.taskType.summary.label",
)

QA = TaskKind(
    id="qa",
    requires_document=True,    # v1 decision: QA over uploaded doc only
    mediator_id="qa",
    display_label_key="toolArena.taskType.qa.label",
)

ALL_KINDS: dict[TaskKindId, TaskKind] = {SUMMARY.id: SUMMARY, QA.id: QA}


def get(task_type_id: str) -> TaskKind | None:
    """Resolve a wire-format string to a TaskKind, or None if unknown."""
    return ALL_KINDS.get(task_type_id)  # type: ignore[arg-type]
```

Style: black + isort + autoflake (per `make format-python`). No external deps.
