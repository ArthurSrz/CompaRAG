<objective>
Make retrieval visible to the arena. Each engine's `execute()` returns an `EngineResult` containing the answer **plus** the list of `RetrievedSpan` it pulled from the corpus, with character offsets in the source document. Output: new `EngineResult` + `RetrievedSpan` models, base helper `_locate_span()`, all 5 engines updated, `NormalizedEnvelope` extended, integration tests for the projection.

```python
"""EngineResult + RetrievedSpan — comparable unit across all 5 engines."""

from __future__ import annotations

from dataclasses import dataclass, field


@dataclass(frozen=True)
class RetrievedSpan:
    """One chunk an engine retrieved, projected onto a corpus-source-relative
    [char_start, char_end) interval.

    The interval is the comparable unit the RetrievalJudge uses to compute
    Recall@K / MRR / NDCG against EvaluationQuery.expected_spans.
    """

    source_doc_id: str
    char_start: int
    char_end: int
    text: str             # for display + debugging
    score: float | None   # engine-native score; None if engine doesn't expose
    rank: int             # 0-indexed position in the engine's returned list


@dataclass(frozen=True)
class EngineResult:
    """Engine's typed output. Replaces the bare `str` return."""

    answer: str
    retrieved_spans: tuple[RetrievedSpan, ...]
    retrieval_latency_ms: int
    generation_latency_ms: int
    # Span-lookup failures: chunks the engine returned but whose text could
    # not be located in the source. Counts only — the spans themselves are
    # dropped. Surfaces in normalizer.normalized_fields.
    unlocated_span_count: int = 0
```

Add a module-level helper to `engines/base.py` that engines call to project a native chunk onto a `RetrievedSpan`:

```python
def locate_span(
    corpus: HaystackCorpus,
    source_doc_id: str,
    chunk_text: str,
    *,
    score: float | None,
    rank: int,
) -> RetrievedSpan | None:
    """Project a native engine chunk onto a corpus-relative RetrievedSpan.

    Strategy: read the source document text, find chunk_text via str.find().
    Returns None if the chunk text isn't found (engine normalized whitespace,
    chunk straddles a boundary the engine smoothed, etc.). Caller increments
    EngineResult.unlocated_span_count for each None.

    Note: chunk_text may occur multiple times in source (rare for >50-char
    chunks). We use the first occurrence — over multiple ranks the same
    interval can repeat. The judge is interval-overlap, so repeats don't
    inflate Recall@K artificially.
    """
    doc = corpus.get_document(source_doc_id)
    if doc is None:
        return None
    start = doc.text.find(chunk_text)
    if start < 0:
        return None
    return RetrievedSpan(
        source_doc_id=source_doc_id,
        char_start=start,
        char_end=start + len(chunk_text),
        text=chunk_text,
        score=score,
        rank=rank,
    )
```

This is the **only place** in the codebase that does the `str.find()` projection. Keep the function simple — no fuzzy matching in v1. Failure modes are visible via the counter.

For each engine, do the same shape of edit:

1. Time the retrieval phase and the generation phase separately:
   ```python
   t0 = time.perf_counter()
   native_chunks = retrieve_native_chunks(...)
   retrieval_latency_ms = int((time.perf_counter() - t0) * 1000)
   ```

2. Project each native chunk onto `RetrievedSpan` via `locate_span()`:
   - **Chroma**: each result item has `documents[0][i]` (text) and `metadatas[0][i]["source"]` (doc id). Pass each through `locate_span(corpus, source, text, score=1 - distance, rank=i)`.
   - **Haystack**: `Document.meta["source"]` carries the doc id (Haystack DocumentSplitter preserves metadata). Use `document.content` as the text, `document.score` as the score.
   - **LangChain**: `Document.metadata["source"]` for the doc id, `page_content` for the text. Score may be in `metadata["score"]` or unavailable — pass `None` when absent.
   - **LlamaIndex**: `NodeWithScore.node.metadata.get("file_name")` for the doc id, `node.get_content()` for the text, `node.score`.
   - **txtai**: txtai retrieval returns `(row_id, score)`. The row_id maps to the doc index in `embeddings.index(...)` input — keep that mapping at indexing time so retrieval can recover `source_doc_id`.

3. Filter out spans where `locate_span` returns `None`. Count them in `unlocated_count`.

4. Time the generation phase:
   ```python
   t1 = time.perf_counter()
   answer = await self._llm.invoke(pill, prompt)
   generation_latency_ms = int((time.perf_counter() - t1) * 1000)
   ```

5. Return:
   ```python
   return EngineResult(
       answer=answer,
       retrieved_spans=tuple(spans),
       retrieval_latency_ms=retrieval_latency_ms,
       generation_latency_ms=generation_latency_ms,
       unlocated_span_count=unlocated_count,
   )
   ```

6. **Special case empty corpus**: when `corpus` has 0 documents (rare; would be a misconfiguration), return:
   ```python
   return EngineResult(answer="No documents available to search.", retrieved_spans=(), retrieval_latency_ms=0, generation_latency_ms=0)
   ```

   No exception — the existing engines already handle this gracefully. Preserve that.

Read each engine carefully before editing — they have engine-specific cache plumbing (`IndexCache.get_or_build`) and embedding-validator wraps. Don't disturb those paths.
