<objective>
Replace `POST /tool-arena/compare`'s synchronous JSON response with **Server-Sent Events** so the frontend can render per-engine progress while ingestion + retrieval + mediation happen. Engines run async (the existing `asyncio.gather` stays); the SSE stream multiplexes both sides' progress events plus a terminal `complete` event carrying the existing `CompareResponse` payload.

Mirror the pattern in `backend/arena/streaming.py` (LLM arena's SSE handler) for consistency.

Crucially: this plan addresses the **user's explicit UX requirement** that work-in-progress is visible during multi-second ingestion. Cache hits emit `ingest_done` with `cache_hit=true` and `took_ms=0` so warm engines feel instant.

Back-compat: clients that don't send `Accept: text/event-stream` get the synchronous JSON response unchanged.

Output: SSE handler on the route, `ProgressEmitter` callback plumbed through engines, dispatcher emits events, integration tests via `httpx-sse`.
</objective>

```python
"""ProgressEmitter — engines call this to surface stage transitions.

In production, the MCP server collects emitted events and includes them in
the response envelope alongside the EngineResult. In tests, the default
NullEmitter discards everything (engines must not require an emitter).
"""

from __future__ import annotations

import time
from dataclasses import dataclass, field
from typing import Protocol


@dataclass
class ProgressEvent:
    side: str          # populated by the dispatcher, not the engine
    type: str          # "ingest_start" | "ingest_progress" | "ingest_done" | "retrieval_start" | ...
    engine_id: str | None = None
    pill_id: str | None = None
    payload: dict = field(default_factory=dict)
    timestamp_ms: int = field(default_factory=lambda: int(time.time() * 1000))


class ProgressEmitter(Protocol):
    def emit(self, type: str, **payload) -> None: ...


class NullEmitter:
    def emit(self, type: str, **payload) -> None:
        pass


class CollectingEmitter:
    """Captures events in a list. Used by the MCP server to serialize them
    into the response envelope.
    """

    def __init__(self, engine_id: str, pill_id: str) -> None:
        self.engine_id = engine_id
        self.pill_id = pill_id
        self.events: list[ProgressEvent] = []

    def emit(self, type: str, **payload) -> None:
        self.events.append(ProgressEvent(
            side="",  # filled by dispatcher
            type=type,
            engine_id=self.engine_id,
            pill_id=self.pill_id,
            payload=payload,
        ))
```

Throttling helper for `ingest_progress` (put it in `progress.py`):

```python
class ThrottledEmitter:
    def __init__(self, inner: ProgressEmitter, min_interval_ms: int = 500) -> None:
        self._inner = inner
        self._min = min_interval_ms
        self._last_ms: dict[str, int] = {}

    def emit(self, type: str, **payload) -> None:
        now = int(time.time() * 1000)
        last = self._last_ms.get(type, 0)
        if now - last < self._min and type == "ingest_progress":
            return
        self._last_ms[type] = now
        self._inner.emit(type, **payload)
```

The rag-pill MCP server is request/response — it does NOT support streaming back to the dispatcher today. Two options:

**(a) Buffer events into the response.**
The MCP server creates a `CollectingEmitter` per call, runs the engine, then returns `{answer, retrieved_spans, ..., progress_events: [...]}`. Frontend replays these as fast events at the end — defeats the "show progress live" UX.

**(b) Per-event NDJSON over a long-poll HTTP stream from rag-pill to backend.**
Rag-pill exposes a new streaming endpoint `POST /run-streaming` returning NDJSON. Each line is either a progress event or the terminal result. Backend reads with `httpx.stream(...)`.

**Recommended: (b)** — meets the real-time UX requirement.

Implementation:

```python
@mcp.custom_route("/run-streaming", methods=["POST"])
async def run_streaming(request: Request) -> StreamingResponse:
    body = await request.json()
    pill_id, engine_id, task, goal, document_content, evaluation_query_id = (
        body["pill_id"], body["engine_id"],
        body.get("task", ""), body.get("goal", ""),
        body.get("document_content", ""),
        body.get("evaluation_query_id"),
    )

    corpus = resolve_corpus(document_content)
    pill = registry.get_pill(pill_id)
    engine = registry.get_engine(engine_id)

    async def gen():
        queue: asyncio.Queue[dict] = asyncio.Queue()

        class QueueEmitter:
            def emit(self, type: str, **payload):
                queue.put_nowait({"type": type, "engine_id": engine_id, "pill_id": pill_id, **payload})

        emitter = ThrottledEmitter(QueueEmitter())

        async def runner():
            try:
                result = await engine.execute(pill, task, goal, corpus, progress=emitter)
                await queue.put({"type": "result", "result": result_to_dict(result)})
            except Exception as exc:
                await queue.put({"type": "error", "message": str(exc)})
            await queue.put({"type": "__done__"})

        task_handle = asyncio.create_task(runner())
        try:
            while True:
                evt = await queue.get()
                if evt.get("type") == "__done__":
                    break
                yield json.dumps(evt) + "\n"
        finally:
            task_handle.cancel()

    return StreamingResponse(gen(), media_type="application/x-ndjson")
```
